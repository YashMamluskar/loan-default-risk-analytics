## Known limitations of this testing

- Slicer dropdown clicks, slicer sync across pages and the Clear all slicers button were not exercised through the interface. Please check them once by hand.
- The insight panels are static text generated from the data at build time. They do not respond to filters, and the page says so.
- No bookmarks are used. Navigation buttons and Clear all slicers cover their purpose.
- MySQL was verified on a separate local test instance on port 3307, not on the installed MySQL80 service, whose password was not shared.
- Tests ran on one machine with Power BI Desktop 2.148. Other versions were not tested.
- The PBIX and template hold this machine's data folder as the DataFolder parameter; change it under Transform data on another computer.
